# agent-practices

我的 coding agent 协作实践,主体是一份 [AGENTS.md](AGENTS.md)——写给 AI 编码代理(如 ZCode / Claude Code / Copilot Workspace 等)的行为约束,放在 agent 的指令入口,让它在每次会话中都遵守。

核心思路一句话:**每条规则都是真约束,宁缺毋滥;验证与询问的强度与影响面成正比。**

## 内容速览

- **协作原则**(8 条):决策分层、输入纪律、审计与修改分离、偏好操作而非建议、最小化与复用、失败换方案阈值、子代理并行、故障处置。
- **工作偏好**:对话语言与产物语言约定、交付文档标准(可复制命令 + 已知坑 + 验收标准 + 回滚预案)、长任务后台化与临时产物清理、本机提权方式。
- **边界**(3 条):隐私与数据主权(含「读入即外发」:凭据读进上下文即随请求外发)、署名/代号、不把环境相关的断言写进要分享的产物。

## 怎么用

1. 把 `AGENTS.md` 复制为你的全局指令文件(如 `~/.zcode/AGENTS.md`),或放进具体项目根目录(项目级优先)。
2. 「工作偏好」「边界」里有作者本机的条目(提权方式、临时产物路径等),移植时替换成你自己的实况;涉及具体机器的表述建议写成「先探测、缺失时降级」。
3. 规则贵精不贵多——留不下的规则只会稀释真正重要的那些。
