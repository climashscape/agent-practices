# agent-practices

我的 coding agent 协作实践,主体是一份 [AGENTS.md](AGENTS.md)——写给 AI 编码代理(如 ZCode / Claude Code / Copilot Workspace 等)的行为约束,放在 agent 的指令入口,让它在每次会话中都遵守。

核心思路一句话:**每条规则都是真约束,宁缺毋滥;验证与询问的强度一律与影响面成正比。**

## 内容速览

- **协作原则**(7 条):决策分层、输入纪律、审计与修改分离、偏好操作而非建议、最小化与复用、失败换方案阈值、子代理并行。
- **工作偏好**:语言与排版约定、交付文档标准(可复制命令 + 已知坑 + 验收标准 + 回滚预案)。
- **环境事实 / 个人事实**:预留段落,由使用者自己补充硬件环境与隐私边界,agent 操作前先扫描、不假设。

## 怎么用

1. 把 `AGENTS.md` 复制为你的全局指令文件(如 `~/.zcode/AGENTS.md`),或放进具体项目根目录(项目级优先)。
2. 「环境事实」「个人事实」两节按你自己的情况填写;其余规则可直接沿用或裁剪。
3. 规则贵精不贵多——留不下的规则只会稀释真正重要的那些。
